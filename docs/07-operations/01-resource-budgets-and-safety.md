# 资源预算、故障隔离与验收框架

> **文档状态**：运行时基础实施中；目标设备验收尚未执行
> **整理依据**：用户历轮确认 + “未单独确认项按推荐方案生成”的授权
> **说明**：技术参数的具体默认数值需要在模块实施时验证；本文不构成现网变更指令。

## 安全优先级
P0 原始业务 (Newifi NAT/Wi-Fi、N1 sing-box/Exit Node、Alienware 现有服务/HDD 休眠) > P1 核心采集 > P2 诊断/历史回放/复杂 Widget。不能因监控增加网络转发的必要依赖。

## 分设备预算
| 节点 | 主要风险 | 架构守护 |
|---|---|---|
| Newifi D2 | SSH/iw 多次查询、Flash 写入、路由处理 | 无常驻 Agent；聚合低频只读；限时与串行执行 |
| N1 | Agent/多 Plugin Runtime 占 CPU/RSS、影响代理 | 系统级资源限制、低优先级调度、熔断 |
| Alienware | 数据库写入、历史回放、Widget 查询、HDD 唤醒 | SSD 数据、查询并发上限、分层清理、休眠保护 |

Agent 插件控制循环只有在 `plugins.enabled` 显式开启且信任密钥、grant、私有 staging/runtime/state 目录、可信 launcher 绝对路径、FD/进程数/单文件/虚拟地址空间/CPU 时间硬限制、单制品及 staging 总字节/包数/扫描边界、清理周期/宽限期/单轮删除量/超时、本地状态条目/字节上限、轮询周期和操作超时均显式配置时才启动。launcher 必须是可执行的非符号链接普通文件且不能由 group/other 写入，其直接父目录也不能由 group/other 写入或是符号链接；它在 `exec` 制品前设置硬 rlimit 和 `no_new_privs`。这些值没有默认值，目标设备应根据实测配置；`RLIMIT_NPROC` 是同真实 UID 的共享计数，地址空间与 CPU 时间主要是单进程限制。控制循环独立于指标采样循环，不主动触发 Collector。staging 目录和状态目录分别使用单写者锁；新包写入前按磁盘实况核算，满额拒绝。清理沿用控制轮询，只保护 current/previous；保护集或目录异常时不删除且新包继续被拒绝，但停用和现有版本健康对账仍可运行。本地原子状态文件保存当前/前序包关联及退避/隔离决策，崩溃临时文件在启动时清理。重启必须先收到 Server Desired 并复验暂存包，不能依据本地记录直接启动旧进程。Server 端只有在 SQLite、人类与设备认证、私有制品目录、单包/总字节/包数量/扫描条目上限、每设备 Collection Policy 数量上限及清理周期/宽限期/单轮删除量/超时均显式配置时才挂载持久化 Desired/Reported、Collection Policy、制品和 Owner 路由；默认关闭。策略新键达到容量即拒绝，已有键仍可用更高 Revision 更新或禁用；单份配置另受 64 KiB 协议边界限制。制品导入达到边界即拒绝；周期清理只删除超过宽限期且未被任何启用 Desired 引用的完整包，引用读取失败则停止整轮，并记录扫描、占用、删除量、耗时和错误。插件观测运行时另要求独立 tick/超时、策略数、单轮任务数、总并发、队列观测/样本/字节和单批观测/样本/请求字节上限；其持久队列使用私有目录、单写者锁、校验和、原子替换和目录同步。单条无法装入任何批次的观测在入队前拒绝，队列满时拒绝新观测，不淘汰未确认数据。该本地链路已有测试，但未在目标设备运行验收。

Agent 批量指标队列也默认关闭。启用 `metrics_batch` 必须同时配置 HTTPS、设备 Token、绝对私有状态目录、队列快照数、队列内存字节数、单批快照数和请求体字节上限。该队列只在采样循环内发送，不增加采样频率或创建重试线程；发送失败保留 pending 批次，容量耗尽或原子状态提交失败后拒绝新样本。每次状态变化使用一个 `0600` 临时文件、文件同步、原子替换和目录同步；稳定数据状态只有一个受既有条数/字节边界约束且带校验和的文件，另有一个固定锁文件；重启会恢复同一 pending ID，并清理内部命名的崩溃临时文件。损坏、身份不匹配、越界、目录已被另一进程锁定或权限过宽均拒绝启动，不自动丢弃数据。systemd 示例为 Agent 创建 `0700` 的 `/var/lib/homelab-monitor-agent`。Server 端只有在同时显式配置 HTTPS、设备凭据、私有 SSD 存储目录、单批快照上限和请求体上限时才挂载 SQLite 批量写入路由。启用任何 SQLite 存储还必须显式配置 PASSIVE checkpoint、保留、容量和物理空间回收的全部周期、阈值、工作量及超时。内建聚合要求显式周期、单轮快照数和超时；可选插件聚合启用时独立要求显式周期、单轮待处理观测数、重算扫描数和超时；两者都要求严格递增的四层保留窗口。各自待处理队列、三层写入和确认同事务，原始清理跳过待处理数据。插件乱序数据只在仍有完整原始来源的窗口内重算；过旧数据和扫描预算不足会明确失败。聚合失败或持续积压不会丢数据，但可能阻止原始清理并使容量保护返回 HTTP 507。常规 checkpoint 不等待活跃 Reader/Writer；独立物理维护在 WAL 达阈值时尝试可等待到超时的 TRUNCATE，并在空闲页达阈值时执行单轮页数受限的 incremental vacuum。每轮记录前后主库/WAL/空闲页和错误，不删除行。旧库转换仅在显式迁移开关下于 HTTP 监听前执行一次全库 VACUUM，并预检数据库大小之外的文件系统保留空间。独立保留任务分批清理过期的原始、分钟、小时、日数据与孤立批次凭据；新批次触及硬状态时仍只同步执行有界清理和 PASSIVE checkpoint，复测不安全则返回 HTTP 507，Agent 保留 pending 批次。插件观测 Server 入口另要求显式单批观测数、总样本数和请求体字节上限，复用同一容量管理器。它不更新内建当前态或触发采集。参数尚未在目标设备调优，聚合写放大、积压恢复、TRUNCATE 锁等待和 incremental vacuum 对上报延迟的影响仍需验收。

告警评估默认关闭，启用时必须同时给出运行周期、单轮超时、单轮规则上限、Incident current 总上限、superseded 归档总上限、两个显式持续时间以及 Unknown/Disabled 行为。规则查询在存储层按稳定游标和本轮额度分页，轮次串行执行；下一轮续接并循环回绕，单条规则失败被记录并隔离。样本只来自 Server 已接收的 Current State，不向设备发请求、不启动 Collector，也不增加任何采样频率。已有 Incident 与当前规则 Revision 不一致时保留原状态并报告错误；Owner 显式激活后，旧状态才以原子事务进入归档并清除 current。归档容量满时拒绝激活，不淘汰既有归档或旧 current。归档读取必须指定设备、规则和不超过配置容量的正整数条数上限，只读查询不推进评估或触发采集；保留期限和清理策略仍待确定。

Server 人类认证与指标查询默认关闭。启用时必须同时显式配置 HTTPS、私有 SSD 存储目录、允许的 Origin、Session TTL、登录限速键容量/次数/窗口以及历史查询范围/点数预算；任一参数缺失都会拒绝启动。启用相应聚合后，内建与插件历史各自按同一四层保留窗口选择数据源，并继续受全局点数预算约束；只启用其中一种聚合不会改变另一种历史源。查询只读取 Server 已接收的数据，不触发 Agent 或插件采样，也不改变设备采样频率。插件历史另有显式原始观测扫描数上限，已观测 Descriptor 目录另有显式每设备条数上限；稀疏原始选择器或聚合重算达到上限时返回失败，避免无界 JSON 解码或伪装成完整结果。

插件 HTTPS 控制客户端的请求总超时取自 `plugins.operation_timeout`，与一次轮询的上下文截止时间一致；普通指标发送保留既有独立 HTTP 超时，不随插件参数变化。

## 工程测量
采集成本：单次耗时、CPU 时间、RSS、FD、返回字节、失败次数。主业务影响：WAN/LAN 延迟、吞吐、错包增长、代理连接成功率、Exit Node 连通性、现有服务 p95 响应。候选阈值只能由真实环境基线和重复测试确定，不固定写死。

## 自动降级顺序
暂停限时连接诊断/历史回放 → 降低低优先级采集 → 限制存储写入/清理 → 隔离异常插件 → 必要时停止监控 Agent；不得停用 sing-box、Tailscale、NAT、DHCP 或 Wi-Fi。

## 自动化验收矩阵
| 场景 | 验收原则 |
|---|---|
| Plugin 崩溃/OOM | Agent 自身与网络本职服务保持正常 |
| 插件升级失败 | 旧版本可恢复或安全停止插件；无无限重启 |
| Server 关机 | 不缓存/补录历史，网络与代理独立运行 |
| 新增 100 条规则（负载测试规模） | N1/Newifi 采样任务次数不变化 |
| 并发打开大量 Widget | 查询降级，不触发设备侧新任务 |
| 指标库达配额 | 分层淘汰、硬保护，系统 SSD 不被填满 |
| HDD 休眠 | 不被指标、SMART 或回放任务唤醒 |

## 性能验收策略
先非侵入式观测正常业务，建立基线；用模拟插件、伪数据和隔离测试环境验证故障处理；需要主动吞吐或压测时，另由 Owner 审批维护窗口和可回滚方案。
