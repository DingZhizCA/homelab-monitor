# 核心原则与不可违反约束

> **文档状态**：架构规划（尚未实施）
> **整理依据**：用户历轮确认 + “未单独确认项按推荐方案生成”的授权
> **说明**：技术参数的具体默认数值需要在模块实施时验证；本文不构成现网变更指令。

## 优先级原则
P0 设备本职工作优先于 P1 基础监控，P1 优先于 P2 增强分析。Newifi 必须持续履行 NAT/DHCP/Wi-Fi/防火墙职责；N1 的 sing-box 与 Tailscale Exit Node 不被监控系统阻塞；Alienware 现有服务和休眠 HDD 不得被监控意外干扰。

## 不可违反约束
- 监控不进入网络数据转发关键路径；插件关闭、Agent 崩溃或 Server 断电不会成为路由、代理、DNS 和 Tailscale 的必要依赖。
- 默认不修改路由、NAT、流量分流规则、防火墙、sing-box、Tailscale 配置；未来需要计数规则时单独评审，不能伴随 Agent 启动隐式安装。
- 日常采集被动、低频、限时、限量；Web 查询与告警数量增加不得线性增加 Newifi / N1 的采集负载。
- 所有远程设备访问使用最小权限；Newifi 不持久写入监控历史库，不依赖长期运行的新监控进程。
- 外部插件不等于可信代码；即使完成签名验证也必须隔离进程权限和资源。不能宣称 native plugin 绝对安全。
- Alienware Server 是唯一控制中心。关机期间允许无记录、无补传、无远程告警；路由与代理保持独立运行。
- 历史统计不得以零填补缺失值；准确度不足允许 Unknown / Partial / Estimated。避免按观测点简单求和形成双重计数。
- 休眠 HDD 不做定期 SMART、文件遍历或可能唤醒磁盘的探测。SSD 承担实时数据库，磁盘硬保护优先。

## 故障下的预期行为
| 故障 | 允许发生 | 不允许发生 |
|---|---|---|
| Server 宕机 | 无 Web、无新增监控历史 | N1 网络代理失效、Newifi 网络中断 |
| N1 Agent 或插件崩溃 | 部分指标不可用、Web 告警 | 影响 sing-box/Tailscale 主服务 |
| Newifi 远程采集超时 | 标记 stale，限频重试 | SSH 登录风暴或路由器过载 |
| 数据库空间紧张 | 降采样、限写、清理低优先级层 | SSD 被监控数据挤满 |
| 第三方推送失败 | Web 可记录故障及发送失败 | 阻塞 Agent 指标上报 |

## 架构质量要求
模块化单体应有清晰依赖方向和稳定接口；插件管理、安全授权、时序存储、流量归属分别作为边界模块。所有操作支持结构化日志、错误码、限时执行及审计。性能预算通过实测确认而不是凭估算固定。
