# 业务细节待实现清单

> **文档状态**：架构规划（尚未实施）
> **整理依据**：用户历轮确认 + “未单独确认项按推荐方案生成”的授权
> **说明**：技术参数的具体默认数值需要在模块实施时验证；本文不构成现网变更指令。

## 使用方式
用户明确要求现阶段只确认架构。本清单专门记录已讨论但无需现在拍板的业务细节。开发对应模块时再提出少量必要问题。示例值均不是正式目标。

## 采样、存储与性能
- 每类设备 CPU/内存/网络/Wi-Fi/DHCP/Tailscale/sing-box 的默认采样周期、上报周期、Web 刷新周期。
- 原始数据与批次凭据已采用无默认值的显式保留窗口；具体运行值、分钟/小时/日聚合保留时间、总配额及分类配额仍待目标容量验证。曾讨论原始 24h、分钟 30d、小时 1y、每日 2y 仅作为示例。
- Newifi、N1、Alienware Agent 的 RSS/CPU 候选预算；应先得到业务基线后通过测量决定。
- 数据库存储规模触发从 SQLite 向更强时序引擎演进的阈值。
- 接口统计和 Conntrack 查询的最小可接受成本、动态降级阶梯与验证样本。

## 流量与设备
- Proxy、sing-box Direct、Bypass、Unknown 的详细分类映射；IPv4/IPv6 归属和 NAT 前后关联。
- LAN 内部通信、互联网通信、Tailnet 内部通信以及 Exit Node 出网的边界与展示格式。
- Wi-Fi 设备随机 MAC 的人工确认流程、设备图标与命名、网络拓扑布局。
- 普通终端状态切换时间窗口、设备自动归档阈值、Owner 手动探测默认方式与次数。

## 仪表盘、交互与通知
- 初始 Widget 模板、拖动网格大小、移动端布局、自定义图表参数、主题与导出。
- 告警严重级别具体阈值、采样条件、复核时长、免打扰时段、重复提醒间隔。
- PWA 主屏幕安装、通知订阅引导、Push 测试与实际到达率验收，HTTPS 域名与证书细节。
- 系统模板升级差异 UI、Owner 确认动作、共享仪表盘发布界面细节。

## 后续研究而非现有能力
- OpenWrt 受限 SSH 可执行能力及 Dropbear 构建支持；必要时使用 rpcd/ubus ACL。
- N1 Conntrack 增量导出方式、代理/Bypass 归属的低成本计量机制。
- sing-box 现有规则及 API 对分类流量的可观察性。
- iPhone/Tailnet 实际远端 Web Push 送达和跳转边界。
- 插件进程由 systemd/cgroup 非 root 宿主控制的操作系统实际能力。

## 不进入第一版默认实现
在线插件市场、WASM 双运行时、任意代码表达式、默认常驻抓包、全网周期扫描、完整连接历史永久存储、监控 Server HA、离线历史补录、远程任意 Shell 执行、网络故障自动修复。
